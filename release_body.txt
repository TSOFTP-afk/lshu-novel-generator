## 灵枢 v1.2 — 重大的更新 🚀

面向长篇小说创作的本地桌面 AI 辅助写作工作台。Python + PyQt6 + SQLite。

---

### ✨ 核心新特性

#### 工具栏重构
- **导出 ▾ 子菜单**：导出独立为工具栏下拉按钮，支持 TXT（Ctrl+E）、Markdown、DOCX（Ctrl+Shift+E），与右键菜单一致
- **AI 设置入口提升**：AI 设置移至顶部工具栏「AI ▾」按钮展开面板的最上方
- **视图配置入口提升**：视图配置移至顶部工具栏「视图 ▾」按钮展开面板的最上方

#### MP4 视频背景
- 支持 `.mp4` / `.avi` / `.mkv` / `.webm` 作为动态底层背景
- 玻璃拟态面板自动适配视频背景

#### Ctrl+0 一键重置
- 清空全部视图 / AI / 主题 / 背景等所有用户配置
- 恢复至首次启动的默认状态

#### 专注写作模式
- 一键隐藏侧边栏，进入全屏写作
- 再次点击或展开侧边栏自动退出专注模式

#### 人名快键（v1.1 引入）
- 书籍级自定义快捷键（如 Ctrl+D），一键在光标处插入人物名称
- 支持手动新增、从人物列表选取、删除快键

### 🎨 设计系统

| 特性 | 说明 |
|------|------|
| 玻璃拟态主题 | Design Token 驱动，滚动条玻璃化瘦身（6px），半透明适配背景图 |
| 编辑器脏标记 | 标题 ● 前缀 + 窗口 * 前缀，未保存一目了然 |
| 树枝干图标 | 书籍/卷/组/模板/默认章节 5 种主题感知图标 |

| 抽屉自适应 | 最小宽度动态调整（宽型 340px / 标准 320px），切换时懒加载 |

### 🧠 AI 核心能力

- **多智能体流水线**：Planner → Writer → Auditor → Reviser，支持 budget / quality 双预设
- **多维度审计**：12 维审计框架 + 24 条内置规则 + @DSL 上下文注入 + Pydantic 校验
- **RAG 向量检索**：Qdrant 嵌入式 + 混合检索 + Jina Reranker
- **AI 任务生命周期**：取消机制（cancel_requested 标志位），detached 任务池，任务摘要面板
- **AI 设置按用途分离**：7 个独立配置项，未配置对应项则该功能不可执行
